Цель работы

Изучить инструмент управления конфигурационными файлами chezmoi, научиться создавать резервные копии dotfiles и синхронизировать их через GitHub.

Среда выполнения

  • ОС: Rocky Linux 10.2
  • Оболочка: Bash
  • Инструменты: chezmoi, Git, GitHub

Инициализация Git-репозитория для dotfiles

  • Переход в каталог chezmoi: chezmoi cd
  • Инициализация репозитория: git init
  • Добавление файлов: git add .
  • Первый коммит: git commit -m "Initial commit of dotfiles"

Создание удалённого репозитория на GitHub

  • Создание репозитория dotfiles на GitHub
  • Подключение удалённого репозитория: git remote add origin <URL>
  • Отправка файлов: git push -u origin main

Восстановление конфигурации на новой системе

  • Команда chezmoi init --apply cedar-95
  • Проверка файла: cat ~/.test_alias
  • Результат: alias ll='ls -la', alias gs='git status'

Основные команды chezmoi

  • chezmoi init — инициализация
  • chezmoi add ~/.bashrc — добавление файла
  • chezmoi apply — применение конфигурации
  • chezmoi diff — просмотр изменений
